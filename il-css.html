Imparare il CSS

Il CSS serve per rendere belli i siti web. Con il CSS puoi modificare colori, dimensioni, animazioni, layout e creare siti responsive.

Cos'è il CSS?

CSS significa Cascading Style Sheets. Serve per personalizzare l'aspetto delle pagine HTML. 

h1{
    color: blue;
    font-size: 40px;
}

Colori e Testo

Con il CSS puoi cambiare colori, font e dimensioni del testo. 

p{
    color: white;
    background: black;
    font-size: 20px;
}

Pulsanti con CSS

Il CSS permette di creare pulsanti moderni e animati. 

button{
    background: blue;
    color: white;
    padding: 10px 20px;
    border-radius: 10px;
}

Box e Layout

Con il CSS puoi creare contenitori, griglie e layout responsive.

BOX 
.box{
    width: 150px;
    height: 150px;
    background: purple;
    border-radius: 20px;
}

Responsive Design

Il responsive design permette al sito di adattarsi automaticamente a telefoni, tablet e computer. 

@media(max-width:700px){

    h1{
        font-size: 30px;
    }

}
